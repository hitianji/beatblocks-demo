# BeatBlocks

[Open the demo](https://hitianji.github.io/beatblocks-demo/).

1. Click **Create session** and **Copy invite link**.
2. Open that link on another device.
3. Press **Play** whenever you join. Both devices follow the same beat position.
4. Edit kick, snare, hi-hat, or tempo. Changes enter together at a shared loop boundary.

The session saves changes automatically. Stop, volume, and hi-hat mute affect only your device. Press Play again to rejoin the current beat. **Save local copy** stores a separate copy in your browser.

Keep the demo open while listening. The shared clock compensates for browser-reported audio delay; network conditions and speaker or Bluetooth delay affect exact acoustic alignment.

The standalone frontend runs on GitHub Pages. Shared sessions use a hosted API and database. No account or microphone is required. The invitation link lets its recipients edit the beat.
